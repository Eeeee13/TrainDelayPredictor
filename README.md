# TrainDelayPredictor

Прогноз задержки наземного транспорта на остановке через 10–15 минут.

Модель для бэкенда лежит в [`model/`](model/README.md). Это версия со скором 1.0 на validate.

Пайплайн, которым она обучается, лежит в [`training/`](training/README.md).

Карта воспроизведения дня 06.01.2026 лежит в [`map/`](map/README.md).
